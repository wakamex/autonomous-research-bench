# AHC065 research workspace

Read the official English statement at [`../../sources/atcoder/statements/ahc065.html`](../../sources/atcoder/statements/ahc065.html). Edit only `solution.cpp` unless the run prompt says otherwise.

Submit a candidate for timestamped public evaluation with:

```sh
ars submit --source benchmarks/ahc065/solution.cpp
```

The run's assigned evaluator CPU and one-worker policy apply automatically. Private scores are calculated only after the run and are never shown to the research system.
