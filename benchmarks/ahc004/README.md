# AHC004 research workspace

Read the official English statement at [`../../sources/atcoder/statements/ahc004.html`](../../sources/atcoder/statements/ahc004.html). Edit only `solution.cpp` unless the run prompt says otherwise.

Submit a candidate for timestamped public evaluation with:

```sh
ars submit \\
  --run-dir "$ARS_RUN_DIR" \\
  --problem problems/ahc004 \\
  --source benchmarks/ahc004/solution.cpp
```

The run's assigned evaluator CPU and one-worker policy apply automatically. Private scores are calculated only after the run and are never shown to the research system.
