### Methodology

The approach addresses both stages of the problem:

1. Base Card Distribution: The first 50 cards are assigned values derived from order-statistic quantile lower bounds of the Beta distribution. Since the 50 target values B_1 <= B_2 <= ... <= B_50 are sorted uniform random variables on [L, U], tailoring base card k to the lower tail of the k-th order statistic ensures that each pile receives a substantial base value while keeping the probability of overshooting near zero.

2. Redundant Geometric Denominations: The remaining 450 cards are structured as a redundant geometric progression with ratio r = 1.33 across 40 denominations spanning from 2.0 * 10^12 down to 1. The geometric redundancy provides multiple combination paths to represent any residual target value, preventing bottlenecks caused by bit shortages.

3. Matching and Greedy Initialization: When target values arrive, base cards are verified against targets with a greedy fallback to ensure no pile overshoots. Delta cards are initially assigned using a best-fit decreasing strategy from largest to smallest value.

4. Multi-Neighborhood Simulated Annealing with Time Budgeting: The solution runs continuous independent restarts of simulated annealing using four move operators: single-card transfers, 1-for-1 swaps between piles, 2-for-1 swaps, and 2-for-2 swaps. The execution loop dynamically measures elapsed wall time, running restarts until 1.70 seconds have elapsed per test case, leaving the best encountered assignment in benchmarks/ahc053/solution.cpp.
