### Motivation and Question

Can we improve solution stability and minimize query cost across diverse test cases by combining full arc consistency constraint propagation, constraint-degree ordered branch-and-bound backtracking, scaled particle Markov Chain Monte Carlo, and board-scaled active spatial exploration?

### Short-Form Result

The 50-case benchmark score was reduced from the baseline score of 9,831,000,000 down to 1,845,000,000, achieving an 81.23% reduction in total query cost. Average queries per instance decreased from 196.62 down to 36.90 while executing within 0.17 seconds of CPU time per case. The best known code is stored in [solution.cpp](file:///code/ARS/benchmarks/ahc030/solution.cpp).

### Core Algorithmic Components

1. Full Arc Consistency Engine
After each drill, the solver propagates constraints bidirectionally:
- Removes any polyomino placement overlapping a confirmed 0-oil cell.
- Enforces core upper bounds: if the core oil across polyominoes equals the drilled oil at cell u, all non-core placements covering u are eliminated.
- Enforces capacity lower bounds: if the maximum candidate shapes covering u equals the drilled oil count, candidate shapes must cover u.

2. Constraint Degree Ordered Exact DFS
- Groups polyominoes with identical geometry into symmetry classes, enforcing monotonic placement indexing.
- Orders shapes by remaining domain size and tie-breaks by constraint degree (number of overlap interactions with drilled cells), placing heavily constrained shapes near the root.
- Uses upper-bound and remaining-maximum lower-bound branch-and-bound pruning to evaluate state spaces up to 8,000,000 nominal configurations in under 3 milliseconds.

3. 90-Particle Targeted MCMC Posterior Estimator
- For state spaces exceeding exact DFS capacity, an ensemble of 90 particles samples the solution space using targeted Metropolis-Hastings proposals.
- When posterior consensus reaches 98% across all cells, the solver submits the answer immediately.
- When ambiguity remains, the solver probes the unrevealed cell that maximizes the information gain metric `p * (1 - p)`.

4. Board-Scaled Spatial Exploration Lattice
- Tracks unexplained oil (drilled oil minus oil accounted for by uniquely placed polyominoes), prioritizing adjacent orthogonal cells only for active polyominoes.
- On large boards (N >= 15), applies distance-2 repulsion to space initial probes at Manhattan distance 3, locating polyominoes with minimal blind queries.
- Global oil conservation terminates the run instantly when total oil discovered equals the known total polyomino area.
