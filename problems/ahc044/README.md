# AHC044 package

This package contains the official AHC044 generator and tester sources, the
50 public seeds used by ARS, and the public final standings and performance
mapping used for historical rank reporting.

The files were extracted without modification from the pinned ALE-Bench
`ahc044.zip` artifact whose SHA-256 is recorded in `problem.json`. Private
seeds and generated private inputs are deliberately not part of the package.
An official evaluator supplies them separately after the research run ends.
