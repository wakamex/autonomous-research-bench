# Project instructions

This project is currently doing discovery work. Treat experiments, benchmark runs, infrastructure changes, and result analysis as discovery by default. Do not repeatedly contrast discovery with promotion, warn that discovery is not promotion evidence, or add promotion-related caveats unless the user explicitly asks about promotion, leaderboard publication, or evidentiary standards.

When generalizing benchmark behavior across score directions, problem types, or adapters, maximize reuse of one authoritative scoring path. Express the varying policy as small explicit data or operations instead of duplicating maximize/minimize implementations.

Host-specific access notes, such as how to reach authenticated AtCoder pages, are in `AGENTS.local.md` when that file exists. It is not tracked.
